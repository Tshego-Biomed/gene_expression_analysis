# About This Repository
This project handles analysing and comparing gene expression differences between hepatocellular carcinoma cells as well as adjacent non-tumor cells of the liver.
This is my first gene expression analysis project. At the start of the project, I had developed some beginner gene expression analysis skills from online courses and activities that 
I had done, but I hadn't analysed real world data. I wanted to put my newly gained skills in practice using real world data and see and analyse the data produced, understanding how
it got to be and why it was they way that it was. 

# Code Attribution
The coding written in this project was written by me. I did receive assistance in terms of debugging and correcting errors from the internet and AI, but I completely understand every
line of code and its contribution to the workflow as well as what it produces.I also made use of reference materials received from a Udemy Bioinformatics, gene analysis course that i was 
enrolled in, which included interactive activities and memos to those activities. 

# What I learned
By doing this project I learnt how to understand gene expression data, skills in data inspection and import, gained quality control knowledge, ability to normalise data, differential
expression skills and visualisation skills in heatmaps, pca, volcano plots and MA plots.
